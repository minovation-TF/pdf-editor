# PDF Editor

운영 주소는 `https://minovation-tf.github.io/pdf-editor/`입니다. 대문은 `https://minovation-tf.github.io/meritz-workroom/`, 명함 제작기는 `https://minovation-tf.github.io/namecard-maker/`에서 각각 배포합니다.

가입제안서 PDF를 브라우저 안에서 열어 형광펜, 메모, 스티커를 표시하고 PDF 또는 JPG로 저장하는 단일 페이지 도구입니다.

## 개인정보와 내 문구

- 불러온 PDF와 작성한 내용은 서버로 업로드되지 않습니다.
- `내 문구`와 사용자 스티커는 현재 브라우저의 로컬 저장소에만 보관됩니다.
- 따라서 배포 사이트에 여러 사람이 접속해도 서로의 문구가 섞이지 않습니다.
- 같은 PC의 같은 브라우저 프로필을 함께 사용하는 경우에는 문구가 공유될 수 있습니다.
- 시크릿 창, 브라우저 데이터 삭제, 다른 브라우저나 다른 기기에서는 기존 문구가 보이지 않습니다.

## 저장 형식

- PDF: 표시된 모든 쪽을 `_표시본.pdf` 한 파일로 다운로드합니다.
- JPG: 사용자가 고른 위치에 원본 PDF 파일명과 같은 폴더를 만들고 `001.jpg`, `002.jpg` 순으로 저장합니다. 최신 Chrome 또는 Edge가 필요합니다.

## GitHub Pages 배포

GitHub Pages는 `main` 브랜치 루트를 게시합니다. `index.html`은 실제 편집기인 `pdf-editor.html`로 이동합니다. 사용자 PDF와 편집 내용은 GitHub 저장소에 전송하지 않습니다. 이전 통합 배포 주소의 명함 진입점은 독립 명함 주소로 안내합니다.

## 방문 통계

방문 횟수와 Cloudflare Web Analytics 집계는 `meritz-workroom` 대문으로 옮겼습니다. PDF 편집기는 방문 통계 요청을 보내지 않습니다. 대문 하단에서 `오늘 · 누적`을 표시하며 같은 브라우저에서는 서울 날짜 기준 하루 한 번 증가합니다. 기존 누적 수치는 유지합니다.

공개용 연결 설정은 `meritz-workroom` 저장소의 `assets/home-config.js`에 있습니다. 비밀번호나 비밀 API 키를 넣으면 안 됩니다. PDF 파일, 메모, 내 문구, 스티커 데이터는 통계 서버로 보내지 않습니다.

기존 `pdf-editor-counter` Worker와 `pdf-editor-visits` D1 데이터베이스를 그대로 사용합니다. 허용된 웹 주소는 `https://minovation-tf.github.io`입니다. Worker 코드를 바꾼 뒤에는 `worker` 폴더에서 `pnpm install`, `pnpm run deploy` 순서로 다시 배포합니다. 데이터베이스 구조는 `worker/schema.sql`에 있습니다.

## 편집 방법

- **형광펜:** 글자를 드래그하거나 단어를 더블클릭한 뒤 색을 고릅니다. 한 번에 선택한 여러 줄은 한 묶음으로 저장되며, 어느 줄을 눌러도 전체 묶음을 선택·색상 변경·삭제할 수 있습니다. 형광펜 도구가 유지되어 연속으로 칠할 수 있습니다.
- **밑줄:** 글자 선택 메뉴는 `형광펜 색상 → 직선과 색상 → 물결과 색상` 순서입니다. 직선·물결 버튼은 빨강으로 적용하고, 옆의 빨강·파랑 버튼으로 원하는 색을 바로 적용합니다. 적용 후 밑줄을 누르면 묶음 전체의 색을 바꿀 수 있습니다. 밑줄은 글자 바로 아래에 붙으며, 확대·축소와 PDF/JPG 저장에서도 같은 위치와 물결 간격을 유지합니다.
- **글자 선택:** PDF 글자 위치에 맞춘 자체 선택 표시를 사용하므로 Edge의 글자 선택 미니 메뉴나 문서 앞쪽 여백의 불필요한 파란 선택 표시가 생기지 않습니다. 정방향·역방향 드래그와 단어 더블클릭을 지원하며, 선택 후 `Ctrl+C`로 내용을 복사할 수 있습니다. `Esc`, 다른 도구 선택, 확대·축소로 선택을 취소합니다.
- **영역:** 네모를 그린 뒤 상자 자체를 끌어 이동하고 오른쪽 아래 점을 끌어 크기를 바꿉니다. 선택 시 뜨는 색상으로 다시 칠할 수 있습니다.
- **메모:** `메모` 도구를 선택하고 문서에서 드래그해 상자를 만든 뒤 바로 입력합니다. 네 변과 네 모서리를 끌어 모든 방향으로 크기를 바꾸며, 위쪽의 일반적인 네 방향 이동 아이콘으로 옮깁니다. 패널에서는 내용·글꼴·글자 크기·굵기·글자색·배경색을 바꿉니다. 배경은 기본적으로 투명하며 `배경 투명도`를 0–100%로 조절합니다. 글자에는 투명도를 적용하지 않습니다. 작은 화면에서는 패널 경계의 아이콘으로 설정을 엽니다.
- **스티커:** 진한 색연필 질감의 체크·한 획으로 그린 별·동그라미·엑스·네 방향 화살표와 내 이미지를 붙일 수 있습니다. 모양과 검정·파랑·초록·노랑·빨강을 따로 고릅니다. 붙인 스티커를 선택한 뒤에도 색을 바꿀 수 있으며 화면과 PDF/JPG에 같은 질감으로 저장합니다.
- **실행취소·되살리기:** `Ctrl+Z`로 되돌리고 `Ctrl+Y`로 되살립니다.
- **홈 이동:** 왼쪽 위 굵은 작업실 아이콘을 누르면 대문으로 돌아갑니다. 아이콘에 마우스를 올리면 `홈으로 돌아가기`가 표시됩니다. 패널 닫기 X는 패널 경계에 있고 접은 뒤에는 같은 위치의 아이콘으로 다시 엽니다. 데스크톱의 편집 도구는 상단 한 줄에 모았으며, 형광펜 색상은 형광펜 버튼을 눌러 고릅니다.

메모 폰트 목록에는 제공받은 나눔·온글잎·마루부리 글꼴을 포함했습니다. 검색 가능한 목록에서 글꼴 이름과 예시 문장을 각 글꼴로 미리 보여주며, 보이는 목록의 글꼴부터 불러옵니다. 선택한 글꼴은 문서에 바로 적용되며, 저장할 때 글꼴 로딩이 완료된 뒤 메모를 그립니다.

## 사용자별 저장 범위

`내 문구`와 사용자 스티커는 현재 로그인 계정이 아니라 브라우저 프로필의 저장소에 보관됩니다. PDF를 바꿔도 같은 브라우저에서는 유지되지만, 다른 컴퓨터·브라우저·시크릿 창으로 자동 이동하지는 않습니다. 컴퓨터 간 동기화가 필요하면 로그인과 사용자별 서버 저장 기능을 별도로 추가해야 합니다.

## 글자 선택 회귀 검증

Python의 `reportlab`, `pypdf`, Node.js의 `playwright`, Microsoft Edge가 설치된 환경에서 다음을 실행합니다.

```text
python tests/selection-fixture.py
node tests/text-selection.cjs
node tests/editor-workroom.cjs
```

시험용 한글 표를 생성해 정방향·역방향 드래그, 기본 브라우저 선택 방지, 표의 옆 칸 제외, 여러 줄 묶음 편집·삭제·실행취소, 단어 더블클릭, 복사, 선택 취소, 확대, PDF/JPG 저장을 검증합니다. 회전·잘라내기가 적용된 페이지도 저장 위치를 확인합니다. 결과는 배포에서 제외된 `tmp/selection-qa`에 저장됩니다. Chrome으로 확인하려면 `TEST_BROWSER=chrome`, 배포 주소를 확인하려면 `TEST_URL` 환경변수를 지정합니다.
