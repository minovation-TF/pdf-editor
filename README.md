# PDF Editor

가입제안서 PDF를 브라우저 안에서 열어 형광펜, 메모, 스티커를 표시하고 PDF 또는 JPG로 저장하는 단일 페이지 도구입니다.

## 개인정보와 내 문구

- 불러온 PDF와 작성한 내용은 서버로 업로드되지 않습니다.
- `내 문구`와 사용자 스티커는 현재 브라우저의 로컬 저장소에만 보관됩니다.
- 따라서 배포 사이트에 여러 사람이 접속해도 서로의 문구가 섞이지 않습니다.
- 같은 PC의 같은 브라우저 프로필을 함께 사용하는 경우에는 문구가 공유될 수 있습니다.
- 시크릿 창, 브라우저 데이터 삭제, 다른 브라우저나 다른 기기에서는 기존 문구가 보이지 않습니다.

## 저장 형식

- PDF: 표시된 모든 쪽을 `_표시본.pdf` 한 파일로 다운로드합니다.
- JPG: 사용자가 고른 위치에 원본 PDF 파일명과 같은 폴더를 만들고 `001.jpg`, `002.jpg` 순으로 저장합니다. 최신 Chrome 또는 Edge가 필요합니다.

## GitHub Pages 배포

이 폴더 전체를 GitHub 저장소의 `main` 브랜치에 올리면 포함된 GitHub Actions가 자동 배포합니다.

1. GitHub에서 비어 있는 새 저장소를 만듭니다. 민감한 PDF 원본은 저장소에 올리지 마세요.
2. 이 폴더의 파일을 저장소에 올립니다.
3. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 선택합니다.
4. Actions의 `GitHub Pages 배포` 작업이 끝나면 공개 주소가 생성됩니다.

## 방문 통계

두 종류의 통계를 함께 준비해 두었습니다.

- **관리자용 상세 통계:** Cloudflare Web Analytics 대시보드에서 방문자와 페이지 조회 수를 확인합니다.
- **화면용 카운터:** 오른쪽 상단에 `오늘 · 누적` 방문 횟수를 표시합니다. 같은 브라우저에서는 하루 한 번만 증가합니다.

PDF 파일, 메모, 내 문구, 스티커 데이터는 통계 서버로 보내지 않습니다.

### 1. Cloudflare D1 카운터

현재 `pdf-editor-counter` Worker와 `pdf-editor-visits` D1 데이터베이스가 연결되어 있습니다. 허용된 웹 주소는 `https://minovation-tf.github.io`이며, 편집기 화면에는 같은 브라우저 기준 하루 한 번 방문 수가 더해집니다.

Worker 코드를 바꾼 뒤에는 `worker` 폴더에서 `pnpm install`, `pnpm run deploy` 순서로 다시 배포합니다. 데이터베이스 구조는 `worker/schema.sql`에 있습니다.

### 2. Cloudflare Web Analytics 연결

`minovation-tf.github.io`가 Cloudflare Web Analytics에 등록되어 있고 공개용 사이트 토큰은 `config.js`에 연결되어 있습니다. 상세 방문 통계는 Cloudflare 계정에 로그인한 관리자만 볼 수 있습니다. 이 토큰은 공개용 사이트 토큰이며 비밀 API 키를 넣으면 안 됩니다.

`config.js`의 두 값이 비어 있으면 편집기는 외부 통신 없이 기존처럼 작동하고 방문 숫자도 숨겨집니다.

## 편집 방법

- **형광펜:** 글자를 드래그하거나 단어를 더블클릭한 뒤 색을 고릅니다. 한 번에 선택한 여러 줄은 한 묶음으로 저장되며, 어느 줄을 눌러도 전체 묶음을 선택·색상 변경·삭제할 수 있습니다. 형광펜 도구가 유지되어 연속으로 칠할 수 있습니다.
- **밑줄:** 글자 선택 메뉴는 `형광펜 색상 → 직선과 색상 → 물결과 색상` 순서입니다. 직선·물결 버튼은 빨강으로 적용하고, 옆의 빨강·파랑 버튼으로 원하는 색을 바로 적용합니다. 적용 후 밑줄을 누르면 묶음 전체의 색을 바꿀 수 있습니다. 밑줄은 글자 바로 아래에 붙으며, 확대·축소와 PDF/JPG 저장에서도 같은 위치와 물결 간격을 유지합니다.
- **글자 선택:** PDF 글자 위치에 맞춘 자체 선택 표시를 사용하므로 Edge의 글자 선택 미니 메뉴나 문서 앞쪽 여백의 불필요한 파란 선택 표시가 생기지 않습니다. 정방향·역방향 드래그와 단어 더블클릭을 지원하며, 선택 후 `Ctrl+C`로 내용을 복사할 수 있습니다. `Esc`, 다른 도구 선택, 확대·축소로 선택을 취소합니다.
- **영역:** 네모를 그린 뒤 상자 자체를 끌어 이동하고 오른쪽 아래 점을 끌어 크기를 바꿉니다. 선택 시 뜨는 색상으로 다시 칠할 수 있습니다.
- **메모:** 메모를 누르면 같은 편집 막대에서 굵기, 글자 크기, 폰트, 글자색, 배경색을 바꿀 수 있습니다. 오른쪽 위 `✥` 손잡이와 오른쪽 아래 크기 점을 사용합니다.
- **스티커:** 체크, 색연필 별·동그라미·밑줄, 네 방향 화살표 또는 내 이미지를 붙일 수 있습니다. 한 번 붙이면 선택 도구로 돌아갑니다.
- **실행취소·되살리기:** `Ctrl+Z`로 되돌리고 `Ctrl+Y`로 되살립니다.

메모 폰트 목록에는 제공받은 나눔·온글잎·마루부리 글꼴을 포함했습니다. 목록의 글꼴 이름 뒤에 `가나다 ABC` 미리보기를 붙여 선택 전에 모양을 확인할 수 있습니다.

## 사용자별 저장 범위

`내 문구`와 사용자 스티커는 현재 로그인 계정이 아니라 브라우저 프로필의 저장소에 보관됩니다. PDF를 바꿔도 같은 브라우저에서는 유지되지만, 다른 컴퓨터·브라우저·시크릿 창으로 자동 이동하지는 않습니다. 컴퓨터 간 동기화가 필요하면 로그인과 사용자별 서버 저장 기능을 별도로 추가해야 합니다.

## 글자 선택 회귀 검증

Python의 `reportlab`, `pypdf`, Node.js의 `playwright`, Microsoft Edge가 설치된 환경에서 다음을 실행합니다.

```text
python tests/selection-fixture.py
node tests/text-selection.cjs
```

시험용 한글 표를 생성해 정방향·역방향 드래그, 기본 브라우저 선택 방지, 표의 옆 칸 제외, 여러 줄 묶음 편집·삭제·실행취소, 단어 더블클릭, 복사, 선택 취소, 확대, PDF/JPG 저장을 검증합니다. 회전·잘라내기가 적용된 페이지도 저장 위치를 확인합니다. 결과는 배포에서 제외된 `tmp/selection-qa`에 저장됩니다. Chrome으로 확인하려면 `TEST_BROWSER=chrome`, 배포 주소를 확인하려면 `TEST_URL` 환경변수를 지정합니다.
